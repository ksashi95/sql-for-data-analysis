# SQL for Data Analysis

A structured SQL learning path focused on data analysis, SQL Server, business analysis, and real-world analytics projects.

## Learning Goal

Build strong SQL fundamentals and progress toward writing analytical queries, working with relational databases, and using SQL in real-world Data Analyst and BI workflows.

## Learning Method

Learn → Practice → Analyze → Project → Repeat

## Curriculum

### 01. SQL Foundations

### 02. Filtering & Sorting Data

### 03. Aggregations & Grouping

### 04. Joins

### 05. Subqueries & CTEs

### 06. Window Functions

### 07. Data Cleaning & Transformation

### 08. Advanced SQL

### 09. SQL for Data Analysis

### 10. Database Design & Data Modeling

### 11. SQL Server & ETL

### 12. SQL Projects

## Recommended Practice Flow

1. Learn the concept
2. Write queries from scratch
3. Practice with small datasets
4. Solve business questions
5. Apply the concept in projects
6. Review and improve the query

## Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- Visual Studio Code
- GitHub
